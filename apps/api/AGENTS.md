# Mail-Meow — API Worker

Scope: `apps/api/**`. Parent index: `../../AGENTS.md`.

- `src/index.ts` — exports `fetch`/`scheduled` via `MailMeowWorker`; re-exports `CronTasksWorker`, `OAuth2TokenRefreshWorker` for DO bindings.
- `src/types.d.ts` — `type Env = CloudflareEnv` global via `worker-configuration.d.ts`.
- `src/workers/MailMeowWorker.ts` — Hono + Chanfana routes, D1 sessions (`x-d1-bookmark` header round-trip in `onRequest`), cron → `CronTasksWorker` DO. `reportConfigurationWarnings` logs everything `AppConfigReader.validate()` returns, once per isolate, memoized on `env` identity — a warm isolate outlives a deployment, so keying on the object rather than a module-level boolean is what makes a reconfigured deploy report again. The constructor has no `env` (Hono binds it per request), which is why this cannot live there.
- `src/endpoints/` — route classes, registered **explicitly** in `MailMeowWorker.registerUserRoutes` / `registerPublicApiRoutes`. There is no file-based routing: adding a route means exporting it from `src/endpoints/index.ts` and adding the `openapi.get/post/...` line. `test/routes/routes.test.ts` asserts the same list, so a new route needs an entry there too.
- Route handlers call `createRequestScope(env)` from `@mail-meow/backend-services/composition` and resolve through the container: `scope.get(Tokens.UserService)`, `scope.get(Tokens.ApiKeyService)`, `scope.get(Tokens.ProcessingService)`, … The registry is `backend-services/src/composition/tokens.ts`. Never `new XService(...)`, and never import `@mail-meow/backend-data` at all — not even for a type (enforced by `no-restricted-imports`, with `allowTypeImports` as the single exception). Re-export the shape you need from `@mail-meow/backend-services/<domain>`.
- The container is per request, never a module singleton: it closes over `env`, and a Worker isolate serves requests with different `env` values between deployments. DAOs are registered as memoized factories so `ConnectedApplicationDAO` reads the Secrets Store on first use rather than on every request.
- Routes use the generated Workers `Env` as their environment type. Do not declare per-route `*Env` subsets: they were a type fiction that only stayed correct because of a cast, and the composition root rejected them the moment it required the full binding set.
- `IBaseRoute` owns the parse → validate → enrich → handle → respond flow. Override `enrichRequest` to attach resolved collaborators; do not re-implement `handle`.
- `IUserRoute` exposes `getAuthenticatedUserEmailAddress`, `getAuthenticatedUserId`, and `getAuthenticatedAccount` — the last is what routes pass to a service. `RouteContext` declares both context variables, so the public routes that never read them still typecheck.
- OpenAPI response/security blocks come from `src/openapi/components.ts` (`errorResponses(...)`, `CLOUDFLARE_ACCESS_SECURITY`, `API_KEY_SECURITY`, `NO_SECURITY`). Do not inline an `Exception` schema in a route — that duplication is what `errorResponses` exists to prevent.
- `src/errors/errorResponse.ts` — the single disclosure decision (`toErrorResponse`, `clientFacingMessage`): what status a caught error becomes, whether the 5xx message is substituted, and whether it is the caller's fault. Both `IBaseRoute` and `MiddlewareHandlers` use it. The taxonomy and the envelope now come from `@rexezuge/{errors,http}` (`ServiceError.expose` plus `errorBody`); what stays here is the redaction backstop on the 4xx side — a 4xx message is _authored_ for the caller but a service is free to compose it from client input, and `OAuth2AuthorizationService` interpolates a client-supplied redirect URI into one — and the caller-fault flag, which the two consumers need in opposite halves. `IBaseRoute` **always** answers with the envelope; `MiddlewareHandlers` rethrows when `isCallerError` is false, because the entrypoint's catch-all returns bare text rather than the `{ Exception: … }` shape. Tests: `test/api/errorResponse.test.ts`.
- `src/middleware/` — `index.ts`, `MiddlewareHandlers.ts` (Cloudflare Access auth) and `HttpHardening.ts` (security headers + the `/user/*` rate limit). `userAuthentication` authenticates to an address, then `UserService.upsertUser` resolves it to an `AccountIdentity`, publishing `AuthenticatedUserId` on the context (empty on a pre-0011 database) — so a route hands the services an id, never a bare address.

  **The rate limiter is registered _after_ `userAuthentication` and that order is load-bearing.** Hono runs middleware in registration order, so a limiter installed first sees no identity and silently degrades to a per-IP bucket — every operator behind one NAT then shares a budget, which is the exact failure the identity key exists to avoid, and it is invisible in a test that authenticates one identity. `/api/:api_key/*` is deliberately unthrottled: a 429 on a delivery endpoint is a bounced email the sender will retry into a second bounce.

- `src/generated/spa-shell.ts` — generated by web build; do not edit.

## Auth

- `/user/*` — Cloudflare Access, via `@rexezuge/http`'s `authenticateAccess`. The local `EmailValidationUtil` and the direct `jose` dependency are gone.
  Three things changed, each worth having: the dev bypass is now an explicit allow-list (`bypassAllowed` **and** the address) rather than the mere presence of a var, so a `DEV_AUTH_EMAIL` left in the dashboard cannot quietly disable Access; the bypass address is validated and lowercased like every other address; and every JWT failure collapses to one message, because "signature verification failed" versus "expired" tells an unauthenticated caller exactly which part of a forged token they got right.
- `DEV_AUTH_EMAIL` (no default, local-only) bypasses Access. `authenticateAccess` reads the `ACCESS` binding when present and answers 401 — never "allow" — when it is absent, so a deployment with no Access in front of it is a supported state rather than an open door.
- `/docs`, `/openapi.json` — Chanfana generated (`fromHono`).
- `/api/oauth2/callback/:applicationId` — public; one-time state + PKCE.
- `/api/:api_key/email`, `/api/:api_key/sns` — public; path API key resolved via `ApiKeyService`.

## Routes

Protected (`/user/*`, registered in `MailMeowWorker.registerUserRoutes`):
`GET /user/me` · `PUT /user/me` · `GET /user/applications` · `POST /user/application` · `PUT /user/application` · `DELETE /user/application` · `POST /user/application/oauth2/authorize` · `GET /user/application/api-keys` · `POST /user/application/api-key` · `DELETE /user/application/api-key` · `GET /user/processing/task-runs` · `POST /user/processing/run-task`

Public (`/api/*`):
`GET /api/oauth2/callback/:applicationId` · `POST /api/:api_key/email` · `POST /api/:api_key/sns`

Catch-all: only paths starting with `/user/` serve `SPA_HTML`; everything else returns 404 so `/api/*` is never intercepted. `/` redirects to `/user/`.
